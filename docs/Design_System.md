# Design System

# Purpose

The NasFon Store Design System ensures every page feels simple, trustworthy, and consistent. Every design decision should reduce customer anxiety and increase confidence in shopping online.

---

# Design Principles

## 1. Trust First

* Use real product images.
* Display honest information.
* Avoid misleading UI.
* Make important information easy to find.

---

## 2. Simplicity

* Keep layouts clean.
* Reduce unnecessary steps.
* Use clear labels.
* Avoid clutter.

---

## 3. Accessibility

* Readable typography.
* High color contrast.
* Large touch targets.
* Keyboard-friendly navigation.

---

## 4. Consistency

* Reuse the same components.
* Use consistent spacing.
* Keep button styles uniform.
* Follow the same interaction patterns across the application.

* Button hover
* Loading spinner
* Page transition

# Design Rule

Before introducing any new UI component, ask:

**"Does this make first-time online shoppers feel safer, or does it add unnecessary complexity?"**

If it doesn't improve trust, clarity, or usability, it should not be included in the MVP.
